# Altox Heater

Минималистичное Android-приложение для управления отопителем Webasto через GSM-модуль
**Altox WBUS-6** (и совместимые WBUS-4/5) по SMS. Интернет и аккаунты не нужны.

- Одна круглая кнопка: **Пуск** → «Запуск...» (тикает таймер) → после SMS-подтверждения
  «Нагрев запущен», кнопка становится **Стоп**; выключение работает так же.
  Цвет кнопки: синий — выключен, жёлтый — ждём ответа, оранжевый — греет, серый — не настроено.
- **Статус**: отправляет `STATUS` и показывает температуру ОЖ, салона и ошибки отопителя.
- **Настройки**: номер SIM-карты модуля, SIM-слот телефона для отправки, пароль модуля,
  время работы.

## Протокол

| Действие | SMS                          |
|----------|------------------------------|
| Пуск     | `START` или `START:XX` (10–120 мин) |
| Стоп     | `STOP`                       |
| Статус   | `STATUS`                     |

Если на модуле задан пароль (`PASS:XXXX`), он дописывается перед командой.

Из ответа модуля разбираются строки `HEATER ON 30min` / `HEATER OFF`,
`Temp heater: 50C` (ОЖ), `Temp sensor: 10C` (салон) и `Error code: ...` (`none`/`FF` — нет ошибок).
Подтверждением пуска/остановки служит SMS со статусом, которое модуль присылает при смене
состояния отопителя, поэтому на модуле должна быть включена настройка `SMSW1`.
Если ответа нет 3 минуты, приложение возвращается в прежнее состояние и пишет «Нет ответа от Altox».

## Сборка

JDK 17, Android SDK (platform 36, build-tools 36.1.0), Gradle 8.14:

    gradle assembleDebug   # отладочная: app/build/outputs/apk/debug/app-debug.apk
    ./build.sh             # подписанная релизная: dist/altox-heater.apk

Для `build.sh` нужен свой ключ: `release.jks` в корне проекта и его пароль в `secrets.env`
(`ANDROID_KEYSTORE_PASSWORD=...`). Оба файла в git не попадают, команда создания ключа есть в `build.sh`.

Разрешения: SEND_SMS, RECEIVE_SMS, READ_PHONE_STATE (только для списка SIM-карт).
