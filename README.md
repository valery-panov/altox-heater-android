# Altox Heater

Минималистичное Android-приложение для управления отопителем Webasto через GSM-модуль
**Altox WBUS-6** (и совместимые WBUS-4/5) по SMS. Интернет и аккаунты не нужны.

- Одна круглая кнопка: **Пуск** → «Запуск...» → после подтверждения «Нагрев запущен», кнопка
  становится **Стоп** и показывает, сколько осталось (`03 мин : 12.5 сек`); выключение так же.
  По кольцу кнопки идёт прогресс: отправка SMS, отсчёт до запроса статуса, ожидание ответа.
  Цвета: зелёный — выключен, оранжевый — ждём, красный — греет, серый — не настроено.
- Время работы выбирается ползунком под кнопкой (10–120 мин) и всегда передаётся явно.
- **Статус** (кнопка слева внизу): температура ОЖ и салона, напряжение, пламя, ошибки.
- **Настройки**: номер SIM-карты модуля, SIM-слот телефона для отправки, пароль модуля.

## Протокол

| Действие | SMS                          |
|----------|------------------------------|
| Пуск     | `START:XX` (XX = 10–120 мин) |
| Стоп     | `STOP`                       |
| Статус   | `STATUS`                     |

Если на модуле задан пароль (`PASS:XXXX`), он дописывается перед командой.

Ответ на `STATUS` (WBUS-6):

    HEATER OFF
    GSM (0-31): 28
    VOLTAGE: 12.9V
    HEATER: 7C        температура ОЖ
    SENSOR: 9C        температура салона
    FLAME: NO
    OUTPUT: OFF       выход OUT (обычно светодиод в салоне)

На `START` и `STOP` модуль не отвечает, поэтому после команды приложение само шлёт `STATUS`,
пока не увидит нужное состояние. `HEATER ON` / `HEATER OFF` модуль показывает сразу (пламя и
продувка идут потом), поэтому обычно хватает одного запроса: через 15 с после пуска и через 20 с
после остановки. Если состояние ещё не то, запрос повторяется каждые 30 с, до 2 минут.
Тайминги собраны в начале `Heater.kt`.

## Сборка

JDK 17, Android SDK (platform 36, build-tools 36.1.0), Gradle 8.14:

    gradle assembleDebug   # отладочная: app/build/outputs/apk/debug/app-debug.apk
    ./build.sh             # подписанная релизная: dist/altox-heater-<версия>.apk

Для `build.sh` нужен свой ключ: `release.jks` в корне проекта и его пароль в `secrets.env`
(`ANDROID_KEYSTORE_PASSWORD=...`). Оба файла в git не попадают, команда создания ключа есть в `build.sh`.

Разрешения: SEND_SMS, RECEIVE_SMS, READ_PHONE_STATE (только для списка SIM-карт).
